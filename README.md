# OmniPsyche: The Integrated Self Architect

![OmniPsyche Banner](public/banner.jpg)

**OmniPsyche** is an advanced personality synthesis engine that integrates multiple psychological frameworks into a unified, holistic profile. Powered by **Gemini 3.0 Pro**, it goes beyond simple categorization to provide deep, narrative-driven insights into your psyche.

## 🌟 Key Features

*   **Multi-Framework Integration**: Synthesizes data from **MBTI, Enneagram (Wings & Tritypes), Big Five (OCEAN), Attitudinal Psyche, Socionics, Instinctual Variants, Four Temperaments, and RIASEC**.
*   **Grand Synthesis Engine**: Uses a specialized AI persona ("Psycholinguistic Profiling Expert") to find intersections, conflicts, and synergies between your various types.
*   **Narrative Mirror**: A psycholinguistic profiling tool that analyzes your free-form writing (journals, bios) to predict your personality type automatically.
*   **Strategic Career Pathing**: Provides a ranked list of high-compatibility careers and college majors based on your cognitive and vocational profile.
*   **Dynamic UI**: A futuristic, glassmorphism-inspired interface built with Next.js 14 and Tailwind CSS.

## 🚀 Getting Started

1.  Clone the repository:
    ```bash
    git clone https://github.com/adisabhista/omnipsyche.git
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Set up your environment variables:
    *   Create a `.env.local` file.
    *   Add your Gemini API key: `NEXT_PUBLIC_GEMINI_API_KEY=your_key_here`
4.  Run the development server:
    ```bash
    npm run dev
    ```

## 🛠️ Tech Stack

*   **Framework**: Next.js 14 (App Router)
*   **Styling**: Tailwind CSS, Framer Motion
*   **AI Core**: Google Generative AI SDK (Gemini 3.0 Pro Preview)
*   **Icons**: Lucide React
